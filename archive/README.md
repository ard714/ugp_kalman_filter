# Archive Directory

This folder contains files that are **not part of the active pipeline** but are preserved
for historical reference or potential future use.

## Archived Files

| File | Original Purpose | Why Archived |
|------|-----------------|--------------|
| `pipeline_v2.py` | Experimental v2 benchmark runner with 3-state model, multi-tau sweep, HMM regime filter, and commodity pairs. | Standalone system; not imported by any active file. Superseded by the canonical 4-state pipeline (`main.py` → `run_all_pairs.py`). |
| `dynamic_pci_3state.py` | 3-state Kalman filter variant (state = [β, M, R], X1 exogenous). IEEE paper formulation. | Only used by `pipeline_v2.py` and scratch debug scripts. The active pipeline uses the 4-state formulation in `dynamic_pci.py`. |
| `backtest_v2.py` | Enhanced backtest engine with partial exits, uncertainty-aware sizing, vol gates, and HMM regime filter. | Only used by `pipeline_v2.py`. The active pipeline uses `backtest.py`. |
| `screening_v2.py` | Strengthened 7-criterion pair screening with PCI index, R_t dominance, and rolling ADF stability. | Only used by `pipeline_v2.py`. The active pipeline uses `regime_filter.py` for screening. |
| `paper_replication_3state.py` | Standalone script for replicating the 3-state IEEE paper benchmarks on `DataSet/*.csv`. | Archived from `run_all_pairs.py` to keep the production 4-state runner lean and uncoupled from legacy experiments. |
| `scratch/` | Directory containing scratch development scripts (`check_gradients.py`, `check_nn_rigorous.py`, IEEE text extracts). | One-off development debug scripts that used the archived 3-state model. |
| `chart.md` | Old Mermaid flowchart of the pipeline. | Superseded by the project guide in `README.md`. |
| `audit_report` | Historical audit report from a prior code review. | Reference only. |

## Archived Output Artifacts

PNG files and logs in this directory are benchmark outputs from previous runs. Fresh outputs
are generated by running `main.py` or `generate_all_plots.py` into the root `outputs/` directory.
